# Security Policy

## Scope
This policy covers all smart contracts provided in the `ossify-core` repository:
- `contracts/trait` (RwaCollateral standard)
- `contracts/registry` (RwaRegistry)
- `contracts/reference-rwa` (MockInvoiceToken)
- `contracts/toy-lending-pool` (ToyLendingPool)

## Disclaimer
**IMPORTANT**: All contracts in this repository are **unaudited** and intended for experimental/reference purposes. Do not use them in production without conducting a professional security audit.

## Reporting a Vulnerability
If you discover a security vulnerability within this project, please do not disclose it publicly. Use one of the private channels below.

### Preferred: GitHub private vulnerability reporting
Open **Security → Report a vulnerability** on this repository: https://github.com/Aycode01/ossify-core/security/advisories/new

This opens a private advisory that only the maintainers can see. It is the best option because the report is encrypted in transit and stays inside the repository's issue tracker.

### Alternative: direct contact
The maintainer is [@Aycode01](https://github.com/Aycode01). Reach out privately through the contact options on that GitHub profile.

We will acknowledge receipt of your vulnerability report and strive to address the issue promptly.
